# Founders’ Lodge implementation contract

D-019 authorizes the winner’s clear supported Overworld proposal and exact-footprint administrator approval before construction. Terrain replacement is disabled entirely. Included materials are construction authority, never a repeated grant of loose resources.

The versioned original Lodge definition is 17 × 13 × 12, timber/plaster/stone with a steep roof, lit porch and meeting chamber, communal table/benches, empty storage, Reeve’s desk/books/bed and a milestone lectern. Rotations transform coordinates and block states. Reeve **Mira Ashford** is practical, dryly humorous and meticulous about recording everyone’s work; she opens real kingdom/milestone views, without granting bank/trading/Charter services.

Server state: permanent winner → available entitlement → claimed token → exact proposal → administrator-approved proposal → permanently redeemed project → progressive construction → required-block verification → one registered Reeve → completion. Claim/recovery durably rotates the token before item delivery, invalidating every old/copy item and any previous proposal/approval. A full inventory is checked before rotation. Delivery interruption can be recovered without issuing another legitimate entitlement. Beginning durably revokes the item’s authority before removing the physical plan; a delayed player save cannot redeem it twice.

Construction writes progress conservatively and never replaces player edits. Claimed progress missing after an uncertain chunk save or damage pauses for administrator inspection; it is not blindly regenerated, which could duplicate included materials. Break/place/explosion/piston protection applies to active reservations. Per-block placement cancellation uses verified NeoForge events; any specific protection mod still requires its own compatibility test. Loaded chunks and a safe reachable work position are required; no chunk tickets or teleports are used.

Pre-existing snow must be cleared before proposal/approval, just like every other obstruction. After redemption, thin weather snow that accumulates in the protected, originally empty reservation may be replaced by the planned block without drops. Full snow blocks, terrain, containers and all other unexpected blocks still pause work. This handles weather during long builds without allowing resource regeneration or destruction of existing property.

UI, defined before implementation: Royal Gilded **Blueprint / Project / Royal Admin** tabs within the existing responsive slate/gold/parchment shell. Blueprint shows winner/claim/recovery and an exact server-reviewed location/rotation. Project shows real phase, block count, progress bar, Aldric’s activity and precise pause reason. Royal Admin shows the current proposal, bounds, zero terrain changes and a separate review/confirm approval; server permission and proposal/revision/expiry checks run again on confirmation. A persistent advisory footprint in the world identifies the reviewed site without placing ghost blocks on the server. Cancellation closes a review without mutation. Every mutation requires a one-use actor-bound server review. Correlated replies cannot reopen a closed screen; uncertain replies require refresh.

Named NPC issuance is reserved durably before spawning; a missing issued NPC is never silently recreated. Damage suspends services. Safe non-destructive resume/reassociation is allowed after exact-ID inspection; arbitrary death/resurrection and destructive repair remain decisions, not automatic features.
