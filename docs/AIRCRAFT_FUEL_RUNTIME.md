# Corin’s refueling supplies

Corin’s Royal Supplies screen sells a fixed physical coal pack through the existing finite canonical shop and private Mailbox. Claim it, then load a compatible native boiler slot using the normal aircraft inventory. Native fuel burn, slot compatibility, shared registration and both claim protections remain in charge. This does not remotely set an engine fuel value or implement a paid instant-fill service.

`serverconfig/kingdomsmp-aircraft-fuel.json` schema1 defaults: pack16coal,8coins/coal (128coins/pack),128coal shared UTC-day stock. These bounded configurable numbers are ordinary implementation defaults, not finalized long-term economy balance. Whole-pack stock must be divisible by the pack size. Fractional/malformed policies refuse instead of silently resetting. The server derives the pack size/price; client quantity/amount fields cannot enlarge it. Old review/repeated claim cannot buy or deliver twice. Existing SHOP_BUY, native player receipt, archive and private-item claim protocols are reused; no new money authority or world-fuel write is added.
