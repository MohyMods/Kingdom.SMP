# Alpha limitations

- This is Tier 1–6 Alpha scope, not full 1.0. Six other professions and Tier 7–12 remain deferred; implemented earlier content and saved progress are retained.
- The automated compatibility profile pins 29 artifacts. The owner's entire 277-mod pack, arbitrary mod combinations, real community economy balance and 2–3-week profession duration are not certified. Native tests use explicit raw inputs, controlled sites and documented private time acceleration; they do not simulate weeks of gathering.
- Library has documented Alpha substitutes for otherwise inaccessible future-tier objectives. The original approved baseline remains preserved; future requirements are not silently unlocked.
- Tree felling requires exact tracked native growth. Historical unknown trees and unsupported species fall back to ordinary single-block mining. Newly grown compatible vanilla/Aether/Twilight/Ars trees can be tracked; only explicitly executed species are certified in the test report. Leaves use native decay and drops, not fabricated harvesting.
- Wand scope is plain supported vanilla full cubes. It excludes containers, machines, ores, stateful/fluid blocks and unrestricted copy/paste. Matching replacement permanently consumes reviewed old blocks without refunds. Maximum selection axes and transaction sizes are bounded.
- Native tools stop when chunks unload, a claim changes, the player changes tools, or world geometry changes. Resume with a new legitimate operation. No permanent chunk tickets are created.
- Economy auctions retain their supported safe component/item scope. Rich modded containers and custom ownership data are refused rather than stripped.
- Sandbox supplies are available only with explicit isolated-world opt-in and OP4. Additional progression/profession/construction sandbox accelerators remain unimplemented. Do not bypass canonical rank, source or reward evidence to speed tests.
- Workstation models reuse vanilla model assets with separate registered identities and Royal Gilded services. They do not add animated furniture models.
- See the actual test report for graphical/client and aircraft flight acceptance boundaries; the manual checklist is not an executed-test claim.
